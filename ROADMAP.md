# Roadmap Nekara Plugins

## Aktuální release

**NekaraRPG 2.3.3**: nativní RPG postup, 13 aktivních dovedností, custom zbraně,
XP zdroje, tematické perk-tree mapy, Power milníky, gathering double dropy,
New Game+ a sjednocené GUI.

## Bezprostřední priorita

1. Živě ověřit hlavní menu, všech 13 perk-tree map, Power 1/25 milníky a návratová
   tlačítka s aktuálním resource packem.
2. Vyvážit XP, gathering dropy, cenu perků, bojové efekty a crafting tier požadavky na stagingu.
3. Ověřit restart, SQLite migraci, Rested XP, Rybaření, Echo Vein a custom zbraně.
4. Teprve po ověření nasadit přesný release JAR na produkční server.

## Následné směry

- Dopracovat Runotepectví a návrh vlastních run bez nahrazení vanilla enchantingu.
- Navrhnout perk-tree pro budoucí Přežití.
- Rozšířit resource pack o finální textury vlastních zbraní a stavů perk cest.

## Mimo rozsah

- Nevracet neaktivní Obchodování a Umění dlaně bez nového návrhu jejich XP,
  perků, GUI a balancu.
- Nevytvářet paralelní externí skill systém.
