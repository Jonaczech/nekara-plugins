# NekaraRPG 2.9.0 – Runotepectví, custom itemy a sockety

Tato verze zavádí první kompletní runový průchod, GUI tvorbu vlastních předmětů a jednotnější zpracování kvalitní výbavy. Vanilla enchantování zůstává zachované.

## Hlavní změny

- Prázdná runa → Magická runa → Tier I–III u enchanting table → probuzení na lecternu. Každý krok přidává XP do Runotepectví a má audiovizuální odezvu.
- První Runa poznání přidává `+1 / +3 / +5 %` XP, je opakovatelná a lze ji vložit do všech socketů.
- Běžná a Neobyčejná kvalita má 1 socket, Vzácná a Epická 2, Legendární 3.
- Runotepecký perk-tree má hodnosti, dvě větve, standardní šipky a bonusy pro vanilla enchanting, ceny run, suroviny, XP i New Game+.
- `/nrpg item create` otevírá GUI editor custom itemů se stabilním ID, modelem, kvalitou, statistikami a dovednostními požadavky.
- Lore výbavy je kratší, správně skloňované a používá barvu kvality i symboly pro sockety a výkov.
- Výkov vyžaduje kladivo stejného nebo vyššího tieru. Chainmail a kůže čekají na Fletching Table.
- Bone meal přidává barvitelné květiny a pouštní vegetaci bez cactusu.
- Kamenné vybavení nemá požadavek pro nošení, vyrábí se od Řemesla 1 a pasivní gathering XP není vázané na nástroj.
- Prázdná runa může velmi vzácně přijít z rybaření a amethyst shard z Kopání.

## Kompatibilita a provoz

- Purpur/Paper 26.1.2 a Java 25.
- Resource pack je samostatný projekt; plugin zachovává vanilla fallbacky.
- GitHub release neznamená nasazení na produkční server. Před výměnou JARu je nutné server zastavit, ověřit SHA-256 a provést plný restart.
