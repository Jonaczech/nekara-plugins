# NekaraRPG – podklady pro ikony dovedností

Tento soubor popisuje 13 aktivních dovedností. Text lze vložit do generátoru
obrázků jako podklad pro samostatné herní ikony.

## Společný styl

- Původní temné středověké fantasy Nekary.
- Jedna silná silueta uprostřed.
- Čitelné i jako malá inventářová ikona.
- Tmavé pozadí, jemné tyrkysové a žhavé oranžové akcenty.
- Bez textu, písmen, čísel, rámečku, loga a cizích herních assetů.

## Dovednosti

| Dovednost | Co dělá | Motiv ikony |
|---|---|---|
| Řemeslo | Vyrábí lepší výbavu, odemyká kvality Tier II–V, šetří materiál a opravuje výstroj. | Kovadlina s žhavou jiskrou. |
| Runotepectví | Posiluje očarování, snižuje jejich náklady a pracuje s runami. | Otevřená runová kniha se zářícím symbolem. |
| Alchymie | Vaří silnější lektvary, zrychluje vaření a spojuje účinky. | Skleněná baňka s tyrkysovým lektvarem. |
| Těžba | Těží rudy rychleji, dobývá žíly, taje rudy a pracuje s řízeným TNT. | Krumpáč, krystaly a jiskry z hlubin. |
| Lesnictví | Kácí stromy, pracuje s listím, saplingy a Tree Fellerem. | Sekera, list a kus kmene. |
| Kopání | Kope zeminu a písek, hledá poklady a obnovuje půdu. | Lopata vedle staré mince nebo střepu. |
| Statkářství | Pěstuje plodiny, chová zvířata, stará se o včely a sklízí pole. | Svazek obilí, malá stodola a včela. |
| Rybaření | Chytá ryby, zkracuje čekání na záběr a hledá vzácné úlovky. | Rybářský háček nad tmavou vodou. |
| Lehké zbraně | Rychlý boj, krvácení, kritické zásahy a obratnost. | Úzká dýka s jemnou tyrkysovou stopou. |
| Těžké zbraně | Pomalé silné údery, průraz zbroje a drtivá síla. | Velká válečná sekera nebo kladivo. |
| Lukostřelba | Přesná střelba lukem a kuší, kritické zásahy a speciální šípy. | Napnutý luk se šípem. |
| Lehká zbroj | Úhyb, pohyb a ochrana lehké výstroje. | Kožená kapuce nebo lehký nárameník. |
| Těžká zbroj | Vysoká ochrana, odraz poškození a výdrž. | Ocelová přilba nebo těžký štít. |

## Doporučený prompt

```text
Vytvoř samostatnou ikonu pro dovednost [NÁZEV].
Význam: [CO DĚLÁ].
Hlavní motiv: [MOTIV IKONY].

Původní temné středověké fantasy pro Minecraft MMORPG Nekara.
Jedna výrazná silueta uprostřed, čitelná jako malá inventářová ikona.
Tmavé pozadí, jemné tyrkysové a žhavé oranžové akcenty.
Bez textu, písmen, čísel, log, rámečku, vodoznaku a cizích herních assetů.
```

`Umění dlaně` a `Obchodování` jsou v datech zachované, ale hráčům se nyní
nezobrazují. Ikony pro ně proto nejsou součástí sady.
